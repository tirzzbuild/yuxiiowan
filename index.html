DOCUMENTATION

Bantuan & Keamanan

Panduan penggunaan YuxiioDev.

Keyboard shortcut

Ctrl + K: buka bantuan · Ctrl + D: ganti tema · Esc: tutup dialog.

Keamanan

  • API key AxzyeDev disimpan sebagai environment variable di Vercel.
  • Supabase service-role key hanya boleh digunakan di backend.
  • Setiap request backend memverifikasi access token Supabase dan role pengguna.
  • Rate limit dasar diterapkan per user. Untuk skala besar gunakan rate limiter terkelola.
  • Jangan mengirim password, token, atau data sensitif lewat chat atau log.

YuxiioDev Help

Gunakan API Services untuk mengirim request. Semua respons dan status disimpan sebagai riwayat pribadi pada akunmu.

  • Ctrl + K membuka halaman bantuan.
